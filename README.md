# Inferring Factor Importance in an Explainable AI Model for Macrophage Immune Cell Polarization

This repository contains the computational models and code associated with the research article:

**“Inferring factor importance in explainable AI model for macrophage immune cell polarization.”**

The workflow combines a mechanistic COPASI model of macrophage polarization with a surrogate Long Short-Term Memory (LSTM) neural network and explainable AI methods to identify influential regulators of macrophage state transitions.

## Repository Contents

### `macrophage_simulation_model.cps`

This file contains the mechanistic macrophage polarization model implemented in **COPASI**.

The model is used to generate large-scale parameter scans representing a wide range of macrophage activation conditions. These simulations provide the time-series data used to train the surrogate LSTM model.

The file can be opened directly in COPASI to:

- inspect the mechanistic reaction network,
- reproduce model simulations,
- perform parameter scans, and
- generate datasets for downstream surrogate-model training.

### `lstm_surrogate_model.py`

This Python script implements the surrogate LSTM model and is designed to run directly in a **Google Colab** environment.

Using parameter-scan outputs generated by the COPASI model as input, the script:

- processes simulated macrophage time-series data,
- trains an LSTM surrogate model,
- reconstructs temporal macrophage marker dynamics,
- applies explainable AI analyses to the trained model, and
- generates relative feature rankings that estimate the contribution of individual factors to macrophage state transitions.

The resulting figures and feature-ranking outputs are formatted to correspond closely with those presented in the associated research article.
